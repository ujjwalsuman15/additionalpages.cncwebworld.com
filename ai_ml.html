What Will You Learn?

Artificial Intelligence enables software and machines to perform tasks that normally require human intelligence. Machine Learning is one of the major approaches used to build systems that learn patterns from data.

This course takes learners from Python and data fundamentals through supervised and unsupervised learning, deep learning, natural language processing and computer vision.

The focus is practical: understand the concept, implement it in Python, evaluate the result and apply it to a real-world project.
